# الاستبيانات الشهرية للفروع

## فترة الاستبيان

- يعتمد موعد الاستبيان على تاريخ اليمن (`Asia/Aden`). يبدأ استبيان الشهر في آخر يوم منه.
- تبقى كل فترة شهرية غير مرسلة مطلوبة بعد بداية الشهر التالي، وتظهر الفترات المتأخرة بدءًا بالأقدم.
- تُحفظ كل إجابة تحت معرف `surveyId__branchId__YYYY-MM` الخاص بشهرها. لا يتغير الشهر عند تأخر الإرسال.
- يبدأ احتساب الفترات من حقل `startsFrom` في تعريف الاستبيان، بصيغة `YYYY-MM`.
- حساب الأدمن معفى من حارس الاستبيانات عند فتح صفحة الفرع.

## الوثائق الصحية للعمال

نوع السؤال الجديد هو `health_documents`. لأجل الاستبيانات الحالية، يعامل التطبيق سؤال `document` الذي يحمل عنوانًا مثل «وثائق صحية» أو معرفًا يحوي `health_documents` بالطريقة نفسها. تبقى بقية أسئلة `document`، ومنها رخصة المحل، كما هي.

```json
{
  "id": "health_documents_question_id",
  "type": "health_documents",
  "label": "وثائق صحية",
  "required": true
}
```

تُحفظ إجابته تحت معرف السؤال في `answers`، في مصفوفة `workers`. لكل عامل معرف ثابت، الاسم الرباعي، رقم الهوية، رقم الهاتف، تاريخ انتهاء الشهادة الصحية، وتاريخ انتهاء شهادة التثقيف. يمكن إضافة أكثر من عامل أو حذف عامل. عند إرسال سؤال مطلوب، يلزم عامل واحد على الأقل واكتمال بيانات كل عامل؛ ويمكن حفظ المسودة قبل ذلك.

## إعادة استخدام بيانات الشهر السابق

عند فتح فترة شهرية، يعرض التطبيق مسودة الفترة نفسها أولًا إن وجدت. وإذا لم توجد، يقرأ إجابة الشهر السابق مباشرة إذا كانت مرسلة، وينسخ الحقول التي ما زالت موجودة في نسخة الاستبيان الحالية، ثم يعرض تنبيهًا للفرع بمراجعتها. النسخ يملأ النموذج فقط؛ ولا يُنشئ استجابة للشهر الجديد إلا عندما يضغط المستخدم «حفظ مسودة» أو «إرسال الاستبيان». إذا حفظ المستخدم مسودة، يُحفظ مصدر البيانات معها لكي يظهر التنبيه مرة أخرى عند استعادتها.

## رسائل الأخطاء في الواجهة

تظهر أخطاء تحميل الاستبيان والتحقق من الحقول والحفظ في نافذة منبثقة فوق الصفحة. عند نقص حقل مطلوب تشير الرسالة إلى السؤال، وإلى رقم العامل عند نقص بياناته. يمكن إغلاق النافذة بزر «فهمت» أو Escape، ثم متابعة تعبئة النموذج. عند فشل التحميل يظهر زر «إعادة المحاولة» بعد إغلاق النافذة.
