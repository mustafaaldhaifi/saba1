# لوحة التحكم

## نطاق المرحلة الحالية

لوحة التحكم مخصّصة للقراءة والإدارة والتقارير. لا تسمح هذه المرحلة من الواجهة بإضافة المنتجات أو حذفها أو تعديل بيانات المنتج أو كميات الطلبات أو حالات الطلبات.

## العمليات المتاحة

| العملية | الصلاحية | البيانات المستخدمة | الأثر |
| --- | --- | --- | --- |
| تحميل اللوحة | المدير فقط | المستخدم الحالي، الفروع، الأنواع، الإعدادات والتواريخ | قراءة البيانات وعرضها فقط |
| تحميل أنواع الطلبات | المدير فقط | `types` | قراءة الأنواع لمرشح اللوحة فقط؛ لا يغيّر Firestore أو التخزين المحلي |
| تحميل إعدادات النوع | المدير فقط | `settings/{typeId}` و`settings/allowableEdits` | قراءة حالة الطلب وسماح التعديل فقط؛ لا يغيّر Firestore أو التخزين المحلي |
| تغيير المدينة أو النوع أو التاريخ | المدير فقط | الفروع والمنتجات والطلبات | قراءة وتحديث حالة الواجهة فقط |
| فتح/حذف تاريخ | المدير فقط | `openDates` | إضافة أو حذف تاريخ مفتوح |
| تغيير حالة الإضافة أو سماح التعديل | المدير فقط | `settings` | تحديث إعدادات النظام فقط |
| فتح الفرع | المدير فقط | الفرع المختار | حفظ الفرع المختار ثم الانتقال إلى صفحة الفرع |
| تصدير PDF أو Excel | المدير فقط | البيانات المعروضة | إنشاء ملف على جهاز المستخدم؛ لا يغيّر Firestore |
| تسجيل الخروج أو مسح الكاش | المدير فقط | الجلسة والتخزين المحلي | لا يغيّر بيانات الطلبات أو المنتجات |

## قرار إعادة التنظيم

أي عملية جديدة يجب أن توثّق هنا قبل إضافتها، مع الصلاحية، مجموعات Firestore المتأثرة، أثرها على التخزين المحلي، وحالات الفشل. عمليات تعديل المنتج والطلب مستبعدة من لوحة التحكم؛ إذا احتاجها النظام لاحقًا فستُنفّذ في ميزة مستقلة مع صلاحيات واختبارات خاصة بها.
